# Methodology

## Research question

Can heterogeneous reasoning trajectories generated by multiple language models be represented as a graph, and can graph structure provide useful signals for selecting or aggregating reasoning paths more effectively than independent candidate ranking?

## Formal objects

A reasoning node is r_i = (id_i, c_i, m_i, deps_i), where id is a node identifier, c is text content, m is generating model, and deps are explicit dependency identifiers.

A candidate trajectory is a structured set of reasoning nodes associated with one model/sample and candidate answer.

Given embeddings e_i and e_j, semantic similarity is s(i,j) = cosine(e_i,e_j). A similarity edge is added when s(i,j) >= tau, subject to configured top-k and model constraints.

A dependency edge is added when a node explicitly lists another node as a prerequisite. A community is a structural partition returned by the community detector; semantic interpretation requires independent validation.

## Candidate scoring

The full graph can include dependency edges, cross-candidate similarity edges, and hybrid edges. Similarity edges are weighted by cosine similarity; dependency edges use a configurable fixed weight.

Pipeline: load frozen candidates; embed reasoning units; build graph; optionally detect communities; compute node scores; average scores within each candidate; choose the deterministic maximum.

Candidate-level graph scores are ranking signals, not correctness estimates.

## Separate answer-level baseline

The embedding-similarity baseline builds a graph directly over candidate answers without reasoning-node propagation.

## Complexity

For N reasoning nodes and embedding dimension D: dense cosine similarity costs O(N^2 D); top-k construction is O(N^2) in the current implementation; PageRank is approximately O(I|E|) for I iterations; community detection depends on graph sparsity and structure. LLM inference, embedding, and graph computation costs should be reported separately.

## Assumptions

Candidate trajectories identify reasoning units; similarity is an imperfect proxy for related reasoning; supplied dependencies are meaningful; and the embedding model represents the domain adequately. These are assumptions, not findings.
